# 🍍 Food Empire

A modern and responsive food website built with HTML, CSS, JavaScript, and Bootstrap.

## 🚀 About The Project

Food Empire is a responsive food website designed to showcase fresh fruits and food products through a clean and attractive user interface.

The project focuses on responsive design, interactive elements, and a smooth user experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Google Fonts

## ✨ Features

- Responsive website design
- Modern and attractive user interface
- Light and dark theme toggle
- Interactive shopping cart interface
- Product display with pricing
- Clean and organized layout

## 💻 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Hazemmohamed21/food-empire.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
